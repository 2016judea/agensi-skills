# Ask the Style Question Once

**Rule.** A pure taste choice has no assumption to state, only options to offer. Ask, with a preview of each
option (AskUserQuestion previews, or small rendered samples), before generating. Ask once.

**Why.** Three wrong style guesses in a row in one session, each costing a full regeneration, ended with
*"just ask me what art form I want… going forward."* The opposite failure came later: a direction already
chosen kept being re-surfaced as "which version do you want", which wastes the decision the person already made.

**How to apply.**
- Taste (style, palette, layout with no functional winner) → ask. Technical (routing, data, pricing) → state the
  assumption and proceed.
- After the answer, or when a direction arrives pre-approved, build it as final. No toggles framed as undecided.
- A house style that has been chosen (e.g. one card-art style for a whole product grid) is never offered as a
  menu again; reuse it.
