# Reading-First Magazine Layout

**Rule.** It's a magazine: the text is the product and the layout serves reading.

**Why.** Repeated corrections across issues: *"maximized for readability … it's a magazine"*; *"put more text on
there so the reading experience isnt so choppy"*; *"page 7 describes something that isnt in writing until
page 8."*

**How to apply.**
- One body size for all writing. Too long → more pages, never smaller type.
- An image or diagram follows the passage that mentions it, never precedes it.
- Avoid pages that are mostly art with a sliver of text between long text runs (choppy).
- Photos the writer placed inside an essay stay inside the essay where they put them.
- Coloured text must pass contrast on the actual paper colour.
