# Never Hamstring an Idea by Pattern

**Rule.** Existing patterns shape how you build, never whether.

**Why.** A genuine opportunity (creator-hosted group trips, real seat prices) was found and then parked because it
didn't fit the existing product categories. *"when we brainstorm ways to make money, we should never hamstring
the idea based on whether it fits our pre-existing pattern."*

**How to apply.**
- Present a non-fitting idea exactly like a fitting one: what it is, the number, can it be built.
- Where it would live (own repo, own brand) is decided after, not before.
- Don't write "doesn't fit, your call"; that is a verdict wearing a question.
