# Vary the Interaction, Hold the Skin

**Rule.** A UI variant is a different way of using the thing, not a different coat of paint.

**Why.** Asked for "different looks" on a house-value card, six reskins shipped (six house styles, same layout).
Rejected: *"these are all the same UXs with different colors. I'm asking for different user experiences."* The
round that could be compared was five interaction models on one neutral look: a sortable screener, a
balance-sheet audit that recomputes when you untick estimates, a price tape with a step chart, a statement feed
of changes, a swipe-to-keep book with a running total.

**How to apply.**
- List verbs, not styles: sort, audit, scan, follow, collect, compare, decide.
- Same neutral skin on every variant so the only difference is how it's used.
- A colour variant asks for a taste judgement; an interaction variant asks how the tool gets used, which is
  the decision that matters. Skin after the pick (see ask-the-style-question).
