# Sexy, Not Scholarly

**Rule.** The house look is never the archive look.

**Why.** For a markets magazine, an 18th-century chart-maker as artist in residence and a cream antique-ledger
palette were rejected as *"too old time scholarly."* The magazines should *"feel sexy."* An issue that reads like
a textbook loses an attention-poor reader.

**How to apply.**
- Before picking a palette or artist in residence, build 2-3 live directions and let them choose.
- Old art is content, not mood: it can be placed on a page set in a modern palette.
- Avoid cream/sepia/engraving defaults; reach for confident type, one strong accent, high contrast. But see
  show-the-quiet-option: confident doesn't always mean loud.
