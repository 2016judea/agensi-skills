# sheets/ — the fifteen real drawings the STEMs were measured off

All public domain (Commons `Public domain` licence tag). Run `python3 scripts/fetch_sheets.py` to download them, as 1280px thumbnails for use as
style anchors with `--image`; the originals are at the Commons pages below. `meta.json` is the raw API record.

The sheets carry a real collector's stamp (the crowned ER of the Royal Collection) and inventory numbers. **Never ask the model to reproduce those, and probe every plate for an invented one** — the image engine has been seen forging a real artist's signature unasked.
