# A Brainstorm Is Not a Build

**Rule.** Initiative closes loops they opened; it doesn't open builds they didn't name.

**Why.** In a travel-business brainstorm, a correction to my framing was read as approval and a build agent was
dispatched. *"stop … i didnt say build anything."* The agent was killed after one commit.

**How to apply.**
- Brainstorm output: the idea, the data that checks its premise, then stop.
- A build starts when they name it ("build X", "go", "ship it"). Work surfaced inside a task they already gave
  you is different; finish that.
- Adjacent ideas go in a backlog line, not a dispatch.
