# Open Pre-Loaded with an Example

**Rule.** Show the value before asking for effort.

**Why.** *"this needs to come pre-loaded with an example (once again, not the first time ive given this UX
feedback)."* Same day, a second tool opened on a trade picker. Build agents shipped both blank.

**How to apply.**
- Pick the strongest real example (one that returns a rich result).
- Load it on first visit with no URL parameter. One line labels it: "Example for X. Type your own above."
- Put this in the brief for any subagent that builds a tool; they default to blank.
